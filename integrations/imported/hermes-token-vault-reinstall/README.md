# Hermes Token Vault reinstall package

Installs the Hermes `token-vault` user plugin and enables it in `~/.hermes/config.yaml`.

```bash
tar -xzf hermes-token-vault-reinstall.tar.gz
cd hermes-token-vault-reinstall
./install.sh
```

Effect: large tool results are stored under `~/.hermes/token-vault/artifacts/` and compact summaries enter context.
